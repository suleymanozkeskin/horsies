The `horsies` crate is the Rust client of the horsies core. The Python package and the crate run on one core, `horsies-core`, so a Rust app has the behaviour and the guarantees that the shared pages state. This section states the API of the crate.

A database belongs to one client: the core refuses a database that the Python client installed.

## The Crate

| Item | Value |
|------|-------|
| Crate | `horsies` |
| Minimum Rust version | 1.91 (`rust-version`) |
| Default features | `cli`: the CLI runner and the `horsies` binary, with clap, tracing-subscriber, toml, owo-colors and tempfile |
| Other features | `web` (the axum mount), `tokio-postgres`, `sqlx` |
