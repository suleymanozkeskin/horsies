The `horsies` npm package is the TypeScript client of the horsies core. The Python client, the Rust client and the TypeScript client run on one core, written in Rust, so a TypeScript app has the behaviour and the guarantees that the shared pages state. The package loads the core as a prebuilt native addon. This section states the API of the package.

A database belongs to one client: the core refuses a database that another client installed.

## The Package

| Item | Value |
|------|-------|
| Package | `horsies` |
| Module format | ES modules only |
| Entry points | `horsies`, `horsies/zod`, `horsies/rerun/pg`, `horsies/rerun/postgres` |
| Runtimes | Node 26 or later, Bun 1.4 or later |
| TypeScript | 6.0 or later, for the published types |
| Native addon | One prebuilt platform package, `@horsies/native-<platform>`, that the package manager selects |
| Optional peer packages | `zod` (zod schemas and `horsies/zod`), `pg` (`horsies/rerun/pg`), `postgres` (`horsies/rerun/postgres`), `@opentelemetry/api` (tracing) |

The versions, the platforms and the setup are on [Installation](/horsies/typescript/installation/). The sidebar lists every page of the TypeScript API.
